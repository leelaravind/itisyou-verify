The 3-Step Verification Protocol

Independent Multi-System Verification

The executor shouldn't be the sole witness of its own completion. We query downstream APIs separately to confirm actual record creation.

01STEP 1: INGRESS

Decoupled Inspection Queue

Register an expected outcome webhook via Make, Zapier, or Python SDK. Signs the intended destination record keys without slowing down production workflows.

// Make / Zapier Inspection Hook
POST https://verify.itisyou.com/v1/assert
expect: { target: "hubspot.deal", id: "{{deal_id}}" }
02STEP 2: AUDIT

Direct Destination Inspection

After a configurable settling period (e.g. 5s), ITISYOU queries target APIs directly to inspect state: valid record ID, updated fields, and matching foreign keys.

// Direct Target REST Query
GET https://api.hubapi.com/crm/v3/objects/deals/{{deal_id}}
settling_window: 5000ms // timeout: 5000ms

When verified, an audit record is logged with destination object IDs and timestamps. When evidence is missing or inconclusive, it fires an immediate agency webhook or triggers a retry routine.
