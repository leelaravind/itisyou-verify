REALISTIC OUTCOMES

What our verification queries actually report back

EVIDENCE-BASED RESULTS ONLY

We do not generate subjective confidence scores or promise infallible perfection. We query destination endpoints at the scheduled settling interval and return precisely what the remote server told us:

Checked: Found Records HTTP 200

The target system was reachable and returned the queried record matching your identifier (e.g., Stripe invoice in_1Nk4... exists with status paid).

Record Not Found HTTP 404 / EMPTY

The workflow reported success, but our verification query against the destination API returned zero records matching the payload ID after the settling period.

Could Not Check HTTP 429 / 503

The third-party API is unreachable, timed out, or rate-limited. We log the raw status code and network latency. We never assume or invent a passing result.

TECHNICAL SPECIFICATIONS

Frequently Answered Practical Questions

What if an external API (like HubSpot or QuickBooks) is down?

We record a status of "Could Not Check" with the raw HTTP status and network timing. We never fabricate a pass or fail when the destination is unreachable. Your run log displays the exact connection timeout and timestamp.

Can we export our verification records if we cancel?

Yes. CSV and JSON exports are permanently available inside your workspace. Even after an active subscription ends or pauses, historical logs and proof hashes remain accessible to you and your agency clients.

How is concurrency and rate-limiting handled?

Destination queries respect upstream vendor limits (e.g. HubSpot 100 req/10s, Stripe 100 read req/s). If an endpoint returns 429 Too Many Requests, our verification scheduler waits with exponential backoff within your defined settling window before declaring a state.

How does VAT work for UK and European agencies?

UK businesses are charged standard 20% VAT with automated VAT receipts generated monthly. EU VAT registered businesses can enter their VAT ID at checkout to apply the standard reverse-charge mechanism automatically.
